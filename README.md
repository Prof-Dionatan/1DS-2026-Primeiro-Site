# 1DS-2026-Primeiro-Site

# 🌐 Meu Primeiro Site

Este projeto foi desenvolvido para auxiliar alunos do **1º ano do Ensino Médio** a compreenderem a estrutura básica de um site e os primeiros conceitos do desenvolvimento web utilizando **HTML**, **CSS** e **JavaScript**.

O objetivo é apresentar, de forma simples e prática, como as principais tecnologias da web trabalham juntas para criar páginas interativas.

---

## 📚 Objetivos de Aprendizagem

Ao explorar este projeto, o aluno será capaz de:

- Entender a estrutura básica de um documento HTML.
- Identificar a função do HTML, CSS e JavaScript.
- Criar elementos como títulos, listas, imagens e botões.
- Aplicar estilos utilizando CSS.
- Adicionar interatividade com JavaScript.
- Conhecer conceitos básicos de acessibilidade.

---

## 🚀 Tecnologias Utilizadas

- **HTML5** – Estrutura e organização da página.
- **CSS3** – Estilização e layout.
- **JavaScript** – Funcionalidades e interatividade.

---

---

## 💻 Funcionalidades

O site apresenta:

- ✅ Um título e uma breve descrição.
- ✅ Explicação das tecnologias HTML, CSS e JavaScript.
- ✅ Uma seção de apresentação do professor.
- ✅ Uma imagem ilustrativa.
- ✅ Botão de curtidas ❤️ que incrementa o número de cliques.
- ✅ Botão **A+** para aumentar o tamanho da fonte.
- ✅ Botão **Contraste** para melhorar a visualização do texto.

---

## 🧠 O que cada arquivo faz?

### `index.html`

Responsável pela estrutura da página.

Contém:

- Títulos
- Parágrafos
- Lista de tecnologias
- Imagem
- Botões
- Inclusão dos arquivos CSS e JavaScript

---

### `style.css`

Responsável pela aparência do site.

Inclui:

- Cor de fundo
- Cores dos textos
- Organização dos elementos
- Estilização dos botões
- Posicionamento dos controles de acessibilidade

---

### `script.js`

Responsável pela interatividade.

Implementa:

- Incremento de curtidas.
- Aumento do tamanho da fonte.
- Alteração da cor do texto para melhorar o contraste.

---

## ♿ Recursos de Acessibilidade

O projeto possui dois recursos simples de acessibilidade:

- **A+** → aumenta o tamanho da fonte.
- **Contraste** → altera a cor do texto para facilitar a leitura.

Esses recursos ajudam a demonstrar a importância de tornar páginas web mais inclusivas.

## ▶️ Como executar

1. Faça o download ou clone este repositório.

```bash
git clone https://github.com/seu-usuario/meu-primeiro-site.git
```

2. Abra a pasta do projeto.

3. Clique duas vezes no arquivo **index.html** ou abra-o em qualquer navegador moderno.

Não é necessário instalar nenhuma biblioteca ou framework.
